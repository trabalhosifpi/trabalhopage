# Meus Links e Gostos Pessoais

Projeto desenvolvido em **HTML e CSS** como uma página pessoal para apresentar alguns dos meus interesses e reunir links relacionados a eles.
A página funciona como uma pequena apresentação pessoal, contendo informações sobre mim, meus principais gostos e uma central com links externos.

##  Sobre o projeto

A página apresenta:

*  Nome e uma pequena bio;
*  Interesse por livros e leitura;
*  Interesse por culinária;
*  Interesse por filmes e séries;
*  Links externos relacionados aos interesses;
* Layout adaptável para diferentes tamanhos de tela;
*  Interface com cores em tons de azul e branco.

## 🛠️ Tecnologias utilizadas

### HTML5

O HTML foi utilizado para criar a estrutura da página, incluindo:

* Cabeçalho;
* Seção "Sobre Mim";
* Cards de interesses;
* Imagens;
* Links;
* Rodapé.

### CSS3

O CSS foi utilizado para personalizar a aparência da página, trabalhando com:

* Cores;
* Tamanhos de fonte;
* Espaçamentos;
* Bordas arredondadas;
* Sombras;
* Organização dos elementos;
* Efeitos ao passar o mouse sobre os links;
* Adaptação da página para diferentes telas.

## 📂 Estrutura do projeto

```text
📁 projeto
│
├── index.html
└── style.css
```

### `index.html`

É o arquivo principal do projeto. Ele contém toda a estrutura e o conteúdo que aparece na página.
Entre os principais elementos utilizados estão:

```html
<header>
<section>
<main>
<a>
<img>
<footer>
```

O arquivo também utiliza classes para permitir que cada parte da página seja estilizada pelo CSS.

### `style.css`

É responsável pela parte visual do projeto.

Nele são definidos elementos como:

```css
background-color
font-family
padding
margin
border-radius
box-shadow
display
```

Também foram utilizados efeitos `:hover` para modificar os botões quando o usuário passa o mouse sobre eles.

##  Design

O projeto utiliza principalmente uma combinação de:

* Azul claro;
* Azul mais intenso;
* Branco;
* Cinza para textos secundários.

A página possui um cartão central branco com bordas arredondadas e sombra, criando uma organização semelhante a um cartão de perfil.

##  Links presentes

A página possui links externos relacionados aos interesses apresentados:

* Instagram relacionado à série **The Rookie**;
* Receita de bolo de chocolate;
* Página de uma edição de colecionador de **Jogos Vorazes** na Amazon.

Os links são abertos em uma nova aba utilizando:

```html
target="_blank"
```

##  Meus interesses

### Livros e leitura

A página apresenta meu interesse por livros e destaca **Jogos Vorazes** como uma das minhas sagas favoritas.

### Culinária

Também foi adicionada uma seção relacionada à culinária, acompanhada por uma imagem de bolo de chocolate e um link para uma receita.

### Filmes e séries

A página apresenta meu interesse por séries policiais e de investigação, além de filmes de terror.

## 📱 Responsividade

O projeto utiliza:

```css
width: 95%;
max-width: 680px;
```

Isso permite que o conteúdo se adapte melhor a telas menores, como celulares, sem perder a organização em telas maiores.
